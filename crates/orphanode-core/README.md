# orphanode-core

The Rust analysis engine behind
[OrphaNode](https://github.com/wthrajat/orphanode).

It provides automatic project discovery and exact-universe APIs for JavaScript
and TypeScript reachability analysis. Results include evidence and explicit
coverage diagnostics; incomplete analysis never becomes unsafe cleanup advice.

API documentation is available on
[docs.rs](https://docs.rs/orphanode-core). Architecture and contributor guidance
are in the repository's
[DEVELOPMENT.md](https://github.com/wthrajat/orphanode/blob/main/DEVELOPMENT.md).
