# `@orphanode/win32-x64-msvc`

This package contains the Orphanode native binary for
`x86_64-pc-windows-msvc`.

It is selected automatically as an optional dependency of
[`orphanode`](https://www.npmjs.com/package/orphanode). Do not install it directly.
The launcher verifies `bin/orphanode.exe` against `bin/orphanode.exe.sha256` before
execution.
